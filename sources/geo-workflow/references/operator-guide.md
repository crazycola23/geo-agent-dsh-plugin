# GEO 工作台 · 使用说明

面向日常使用这个插件的人。看完这一页就能自己配、自己用。

## 这个插件是干什么的

让 DSH 能直接操作 GEO 后台：读项目资料、整理事实候选、写内容、发布、做检测、出报告。

**所有写操作都会先弹给你确认**，不会悄悄改 GEO 里的数据。

## 卡片在哪

DSH 左侧「**插件**」→「已安装」里点开 `@geo-internal/geo-agent-dsh-plugin` → 页面上方的「**GEO 工作台**」。

更快的入口：左侧导航直接点「**GEO 工作台**」（同一张配置卡，上方多了流程进度条）。

> 说明：插件**列表页**每一行只显示名称和开关，**配置区在点进去以后的详情页里**。列表上找不到配置项是正常的。

## 怎么看 AI 做到哪一步了

- 会话顶部与「轨迹」并排的「**GEO 进度**」标签：显示当前会话的流程条（项目→资料→事实→问题→内容→发布→检测→报告），AI 每完成一步自动打勾；AI 提了待答复的问题时，顶部会出现黄色横幅提醒你去对话里作答。
- 流程条反映的是 AI 实际调用的 GEO 工具，仅供跟进度；业务结果以 GEO 界面和接口返回为准。

## 第一次要配三样

| 配置项 | 怎么填 |
|---|---|
| GEO 服务地址 | 只填「协议 + 域名/IP + 端口」，例如 `https://192.168.2.110:8443`。**不要带路径**，内网地址也必须 HTTPS |
| 资料投递目录（可选） | 用来上传资料文件；只会读取这个目录下指定类型的文档 |
| 项目授权 | 每个项目填 **项目 ID + 项目 API 令牌**。令牌在 GEO 的「项目档案 → 项目 API 令牌」里创建，**明文只显示一次**，当场粘贴过来；插件保存后不再回显 |

**每个项目必须用自己的令牌**，把同一个令牌配给两个项目会被拒绝。

## 保存后怎么确认配好了

用一次 `geo_connection_status`（或直接说「检查项目 N 的连接」），它会告诉你令牌绑定的项目、权限码和有效期。

## 「运行隔离」开关是什么

| 状态 | 效果 |
|---|---|
| **开** | 本 DSH 里所有助手**只看得见 GEO 的 5 个工具**，看不到终端、文件、浏览器。适合把 GEO 令牌和通用工具隔开 |
| **关** | GEO 工具和其它工具**同时可用**。方便，但令牌和通用工具处在同一个环境里 |

**切换后配置立刻写入**。如果工具列表没有马上变化，**完全退出 DSH 再启动**一定生效 ——
注意「关窗口」只是收进托盘，要用托盘菜单退出、或在任务管理器里结束进程。

## 关于「换 home 为什么要重启」

DSH 把全部身份材料（配置档案、技能、凭据、会话）放在**一个目录**里，由启动时的 `DSH_HOME` 决定。

**这个目录只能在启动前选定** —— 插件是启动**之后**才加载的，所以它没办法在运行中帮你换。
要让 GEO 跑在完全独立的实例里（令牌与日常环境彻底隔开），就换 `DSH_HOME` 再启动：

```powershell
$env:DSH_HOME = 'D:\wt\geo-agent-full-flow\dsh-home-web'
dsh --profile geo-workflow
```

一句话：**换 home = 换一套实例 = 必须重启 DSH。**

日常使用不必这么做，上面的「运行隔离」开关已经够用；只有需要严格隔离时才走这条。

## 说明书本身在哪

- **在 DSH 对话框里**输入 `/geo-workflow` —— 会加载一套 GEO 作业流程与确认规则；
- **在磁盘上**：`<DSH_HOME>\skills\geo-workflow\`（`README.md` 是入口），其中
  - `references/workflow.md` —— 业务阶段与确认节点
  - `references/setup.md` —— 安装与配置
  - `references/capability-map.md` —— 能调用的全部 GEO 操作清单
  - `references/maintenance.md` —— 规格更新办法

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 看不到配置卡片 | ①确认 DSH 是**完全退出**后重启的（关窗口不算）；②插件**列表页没有配置区**，要点进详情页 |
| 令牌被拒 / 提示无权限 | 令牌最长 30 天，过期或被撤销后下一次请求就会被拒 —— 去 GEO 项目档案重新签发一个 |
| 工具列表里少了东西 | 检查「运行隔离」是不是开着；开着的状态下只能看到 GEO 的工具 |
| 改完配置没反应 | 完全退出 DSH 再启动 |
