# 运营员 UI 流程速查（agent 沟通用）

2026-10-07 全站真实点击走查（测试小8 万事达，geo.dev.fj3399.com v44）。Agent 与运营员对话时使用同一套 UI 术语；本页同时记录 UI 与 OpenAPI 的行为差异。

## 全局结构

- 工作台顶部有 **1-8 步骤导航**（项目档案→资料与内容要素→搜索问题→内容生产→媒体中心→发布中心→发起检测→复盘报告），每页提供「前往下一步：X」按钮——OpsRun 的依赖序与此完全同构。
- 「操作记录」（/geo/audit）是全量审计表：时间/操作者/动作/对象/状态变化/原因/金额/外部记录号/请求编号，实时可查——agent 汇报结果时可指引用户来这里核对。

## 术语映射（API ↔ UI）

| API / 契约 | UI 用语 | 备注 |
|---|---|---|
| question status `candidate` | **待启用** | 问题库列表状态列 |
| question `enabled` | **已启用** | 启用后行内出现「生成内容」直达按钮 |
| fact candidate `pending` | **待确认** | 事实候选审核区全局计数（待确认/已确认/已驳回） |
| fact revision confirmed | **已确认** | |
| detection plan `manual_recheck` | 复测类检测计划 | `baseline` = 基线 |
| 租户现金预算桶（cash） | 现金预算 | 拨款申请→管理员批准→入现金预算 |

## 各页真实交互（与 API 的差异用 ⚠ 标注）

### 资料与事实（/geo/facts，一步聚合页）

- 每份资料卡片：未提取时显示「提取事实」按钮；已提取显示「事实提取：已完成 100% · N 条候选」+「事实候选（N）」展开。
- 候选审核区：全局计数 + 搜索 + 状态筛选 + **批量勾选/批量确认**（需先勾选）。
- ⚠ **UI 点「确认」无对话框**：默认 `scope=project`、`publicBoundary=public` 直接生效；API 侧这两字段必填显式传。OpsRun 经 ask_user_question 确认候选时按同一默认即可，仅冲突/敏感候选才追问边界。
- 小文件上传后即时 PARSED。

### 问题库（/geo/questions）

- 默认打开「智能生成」向导（3 步：核心主题→生成参数→数量）；「搜索问题」tab 才是列表；「历史生成任务」是生成任务记录。
- ⚠ **UI「启用」一键完成，无平台选择对话框**（沿用问题创建时已绑平台）；API 直连时 `targetPlatformIds` 必填显式传。
- 启用后行内出现「生成内容」直达按钮（携问题跳内容生产并预填表单）。
- 「快捷生成」菜单项在项目未绑定客户平台账号时置灰——发布链路的前置条件。

### 内容生产（/geo/content，新建任务抽屉）

表单分四段（对应 ContentGenerationTaskCreate，但有一处缺口 ⚠）：

1. 内容目标：任务名自动生成可改；问题可继续加选（提示"生成篇数在所选问题间均衡分配；同一内容机会的问题共同进入文章上下文"）；
2. 内容素材：radio「全部启用的内容要素」vs「指定内容要素（推荐精选 3-5 条）」，UI 主动建议精选避免要素堆砌（API 对应 `contentElementIds`）；
3. 内容形态：内容类型 combobox（品牌专题稿默认，附一句定位说明）；**目标篇幅三档 radio（快读速览 600-1000 / 标准深度 1200-1800 默认 / 长篇权威 2000-3000）+ 自定义区间 300-5000**；
4. 执行计划：立即执行 / 定时执行；生成数量默认跟随所选问题数（上限 20）。

⚠ **契约缺口**：目标篇幅档位在 OpenAPI `ContentGenerationTaskCreate` 中没有对应字段——geo_api 创建任务时无法指定篇幅（服务端按类型给默认）。需要后端确认：契约补字段或明确由 contentMode 推导。
保存后弹「是否立即执行——确认后中途不再询问」；排队中显示「查看排队情况（N）」。

### 发起检测（/geo/detection-run，三步向导）

1. 输入问题：核心主题 textbox（页面指导："写成客户真会问的话，不要写品牌名"）+ 可选参考问题；
2. 生成并确认：LLM 生成默认 10 条（最多 25，可手工补充），逐条勾选/删除；**"这些问题只用于本次检测，不会自动加入正式问题库"**；
3. 确认并开始检测：平台多选（OneGl 豆包/千问/智谱清言/文心一言，默认全勾，均匿名采集）；**费用口径页内明示："本次不预览费用、不预留预算（P-5 待确认）"**；确认后逐题逐平台采集，期间可离开。

⚠ 检测发起**不预览费用**——OpsRun 决策单里检测项的依据只能写范围（题数 × 平台数），金额表述为"事后计入费用台账，由服务端预算硬校验"。

### 预算与费用（/geo/budget）

项目总预算 + 分类桶（未配置的分类显示"尚未配置此预算分类"）+ 拨款申请流 + 费用台账（消费后此处出现记录）。

## 对 OpsRun 的落点备忘

- 决策单"依赖序"= UI 步骤 1-8，顺序已验证一致；
- 候选确认/问题启用按 UI 默认走，不逐条追问；
- 检测项不写金额，写范围与"事后台账"；
- 发布链路前置：客户平台账号未绑定时发布项直接标 blocked（快捷生成置灰是同一信号）；
- 事实确认两段式、问题启用带平台，已在 auto-run.md EXECUTE 节写明。
